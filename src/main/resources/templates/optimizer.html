info How it works

The Kafka Optimizer monitors consumer lag, batch processing duration, and throughput. When it detects sub-optimal performance or resource under-utilization, it suggests or applies dynamic changes to the consumer properties to ensure maximum reliability and efficiency.

warning Dynamic Reconfiguration

Some property changes may require a consumer restart. The application handles graceful re-balancing when these optimizations are applied in production environments.
